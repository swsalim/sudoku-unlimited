# Classic Sudoku rules

A standard Sudoku grid is 9×9 cells, divided into nine 3×3 boxes. Fill every empty cell with a digit from 1 through 9 so that each row, each column, and each 3×3 box contains every digit exactly once. Starting numbers (givens) stay fixed. The puzzle is solved by logic and elimination, not arithmetic.
