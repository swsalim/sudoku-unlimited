# Kids Sudoku

Kids Sudoku is a smaller grid than classic 9×9 Sudoku.

- `/kids-sudoku` explains the rules and links to both sizes.
- `/kids-sudoku/4x4` is playable. Digits are 1–4. Each row, column, and 2×2 box uses each digit once.
- `/kids-sudoku/6x6` is playable. Digits are 1–6. Each row, column, and 2×3 box uses each digit once.

Both play pages can print the current puzzle. The solution prints on the following page.
