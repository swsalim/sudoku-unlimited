# Sudoku difficulty levels

Sudoku Unlimited offers six classic levels: Easy, Medium, Hard, Expert, Master, and Extreme. Harder levels use fewer or more carefully placed givens so solvers need deeper candidate techniques. Each level has its own play URL (for example `/easy`, `/medium`). Killer Sudoku uses the same level names under `/killer-sudoku/`.
