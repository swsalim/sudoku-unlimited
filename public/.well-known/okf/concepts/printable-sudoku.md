# Printable Sudoku

The printable hub at `/printable` links to four sheet pages:

- `/printable/easy`
- `/printable/medium`
- `/printable/hard`
- `/printable/expert`

Each page builds four 9×9 puzzles with the same generator used for that difficulty online, then shows the solutions. Printing puts the solutions on the next page. A PDF download contains the same two pages. New puzzles replaces the sheet in the browser.
