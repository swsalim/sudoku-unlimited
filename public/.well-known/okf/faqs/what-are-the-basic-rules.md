# What are the basic rules of Sudoku?

Fill every empty cell with a digit from 1 through 9. Each row must contain 1–9 with no duplicates. Each column must contain 1–9 with no duplicates. Each 3×3 box must contain 1–9 with no duplicates. Use logic only — no guessing required on a well-made puzzle.
